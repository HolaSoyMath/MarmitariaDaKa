# Frontend

## O que é

Interface da dona. Aplicação web responsiva onde ela realiza todas as operações do ciclo semanal.

---

## Stack

- **Framework:** Next.js (App Router)
- **Estilização:** Tailwind CSS
- **Componentes:** shadcn/ui
- **Ícones:** Lucide
- **Deploy:** Vercel

---

## Onde fica

`apps/frontend/`

---

## Documentação técnica

- `apps/frontend/docs/ARCHITECTURE.md` — camadas, estrutura de pastas, padrões de código
- `apps/frontend/docs/FRONTEND.md` — estado global de semana, TanStack Query, formatters
- `apps/frontend/docs/COMPONENTS.md` — componentes compartilhados e padrões por módulo
- `apps/frontend/docs/UI.md` — regras de exibição, formatação, identidade visual
